## What This Document Set Covers

This is the complete pre-build documentation for Kairon — a multi-market financial intelligence system that scans 6 global markets, uses a team of AI agents to analyze opportunities, calculates net profit after every cost, and recommends capital moves. No real user data is stored. The platform operates entirely in simulation mode using real market data patterns.

1. Start with `01_PRODUCT_VISION.md` — understand the goal
